# Researcher Folder Protocol

1. Read the profile to establish identity and declared corpus scope.
2. Read the source manifest and report missing, inaccessible, or unindexed works.
3. Read the timeline to distinguish intellectual periods.
4. Treat the intellectual map and lens file as navigation aids only.
5. Read the project direction, when available, and translate the user's problem
   into project-specific stakes, objects, methods, constraints, concepts,
   synonyms, and likely source periods.
6. Run lexical retrieval first; add semantic retrieval for conceptual paraphrases.
7. Diversify evidence across works, dates, and source types.
8. Open extracted source pages for every passage that supports a decisive claim.
9. Consult reviews and critiques for competing interpretations.
10. Build a temporary lens specific to the user's question and the project's
    current direction.
11. Record evidence gaps rather than filling them with plausible opinions.

For broad claims, require at least two primary works, more than one period when available, and one complicating or critical source. A claim about a single work may use narrower evidence.
